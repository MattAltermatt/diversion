# Waymark Implementation Plan (#398)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `waymark`, a 2D diversion: one slow ant walks a torus of letter-coloured tiles, reads the letter under it, turns as told, and the tile eases to its next letter while the ant waits; a pre-seeded field of territories gets carved into texture, and renews when 60% of it has been carved.

**Architecture:** Pure modules first, rendering last. `program.ts` (letters, turns), `field.ts` (a **closure** `(col,row) → pointer` fixed per generation, so a resize can extend rows consistently), `step.ts` (tiles as a `Uint8Array` of pointers, ants with a `prog` clock, display-only colour tweens keyed by tile index, renewal), `render.ts` (≤ 4 cached `fillStyle`s + OKLab lerp for the handful of tweening tiles, ant edge marks, renewal crossfade), then `index.ts` wiring. **Tiles never store a colour** — colours resolve from the live config through a small cache, so a palette edit recolours the whole field on the next frame and the per-frame cost is `fillRect` only.

**Tech Stack:** Vite + React 19 + TypeScript + Zod 4, Canvas 2D, Vitest.

**Spec:** `docs/superpowers/specs/2026-09-15-waymark-design.md` — read it first; the plan argues from it. Visual contract: `docs/mockups/2026-09-15-waymark.html` and the PNGs beside it.

```ts
// src/diversions/waymark/program.ts
// The ant's own compass. L/R turn, U = keep going (the ant's "up"), D = turn back.
// NOT turmite's table (there `U` is the U-turn and `N` is straight) — the owner's
// example string was `LUUR`, "left, up, up, right", and `U` means up.
export type Letter = 'L' | 'R' | 'U' | 'D'

/** Heading index → [dx, dy] in cells. 0 E, 1 S, 2 W, 3 N (canvas y-down). */
export const HEAD: ReadonlyArray<readonly [number, number]> = [[1, 0], [0, 1], [-1, 0], [0, -1]]

/** Curated programs. Invariant (tested): no two cyclically-consecutive letters are equal,
 *  so every dwell is a visible colour change — `LRRRRRLLR`, the first default, was a no-op
 *  5 dwells in 9. `LUUR` is the owner's original string and is kept by name despite one U→U. */
export const PROGRAMS = ['LRUD', 'LURD', 'RL', 'LRLU', 'LDRU', 'LUUR'] as const
export type Program = (typeof PROGRAMS)[number]
export const NO_REPEAT_EXEMPT: ReadonlySet<string> = new Set(['LUUR'])

const ALIAS: Record<string, Letter> = { L: 'L', R: 'R', U: 'U', D: 'D', F: 'U', B: 'D' }

/** A program string → letters. Upper-cases, maps F→U and B→D, rejects anything else
 *  and lengths outside 2..12. Throws — a program comes from a Zod enum, never a URL. */
export function parseProgram(s: string): Letter[] {
  const out: Letter[] = []
  for (const ch of s.toUpperCase()) {
    const L = ALIAS[ch]
    if (!L) throw new Error(`waymark: bad letter '${ch}' in program '${s}'`)
    out.push(L)
  }
  if (out.length < 2 || out.length > 12) throw new Error(`waymark: program '${s}' must be 2..12 letters`)
  return out
}

export function turn(h: number, letter: Letter): number {
  switch (letter) {
    case 'L': return (h + 3) & 3
    case 'R': return (h + 1) & 3
    case 'D': return (h + 2) & 3
    default: return h
  }
}

/** The program's classes: the FIRST index holding each distinct letter, in program order.
 *  A tile starts on one of these, so colour is state: two tiles that look alike start alike. */
export function classesOf(letters: Letter[]): number[] {
  const seen = new Set<Letter>()
  const out: number[] = []
  letters.forEach((L, i) => { if (!seen.has(L)) { seen.add(L); out.push(i) } })
  return out
}

/** True when no two cyclically-consecutive letters are equal. */
export function hasNoRepeats(letters: Letter[]): boolean {
  const n = letters.length
  for (let i = 0; i < n; i++) if (letters[i] === letters[(i + 1) % n]) return false
  return true
}
```

**Design notes.** The closure is what a resize relies on: `step.resizeRows` calls the *same* `FieldFn` for appended rows, so existing rows stay byte-identical. `regions` uses **jittered-block Voronoi** — one seed per `BLOCK × BLOCK` cells at a hashed jitter with a hashed class, nearest among the 3×3 neighbouring blocks — which is pure in `(col,row,seed)`, infinite in rows, and has the spec's density (`BLOCK = 10` gives 14.4 seeds per 48×30, the spec's 14). `noise` bakes its quantile thresholds from the initial `cols × rows` population and reuses them for any row later, so extension stays consistent (equal-mass to within the population it was cut on). `random` hashes per cell, no rng stream. `uniform` is `() => 0`.

```ts
// src/diversions/waymark/field.ts
// The starting field: what every tile holds before the ant has touched it. Every kind
// is a CLOSURE (col,row) → pointer that is fixed for a generation, so a resize can call
// it for appended rows and existing rows stay byte-identical. Pointers are always class
// indices (the first program index holding a letter) — colour is state.
import { makeNoise3D } from '../../framework/rng'
import { classesOf, type Letter } from './program'

export const FIELD_KINDS = ['regions', 'noise', 'uniform', 'random'] as const
export type FieldKind = (typeof FIELD_KINDS)[number]
export type FieldFn = (col: number, row: number) => number

/** Cells per Voronoi block: one seed per BLOCK² cells → 14.4 seeds on 48×30, the spec's 14. */
const BLOCK = 10
const NOISE_OCTAVES = 3
const NOISE_ROUGHNESS = 0.4

/** Integer hash → [0,1). Pure in its arguments; no stream, so no call-order dependence. */
function hash(x: number, y: number, seed: number, salt: number): number {
  let n = (Math.imul(x, 374761393) + Math.imul(y, 668265263) + Math.imul(seed | 0, 1442695041) + Math.imul(salt, 2246822519)) | 0
  n = Math.imul(n ^ (n >>> 13), 1274126177)
  n = (n ^ (n >>> 16)) >>> 0
  return n / 4294967296
}

export function makeField(kind: FieldKind, letters: Letter[], cols: number, rows: number, seed: number): FieldFn {
  const classes = classesOf(letters)
  const K = classes.length
  switch (kind) {
    case 'uniform':
      return () => 0
    case 'random':
      return (col, row) => classes[Math.floor(hash(col, row, seed, 1) * K)]
    case 'regions':
      return (col, row) => {
        const bx = Math.floor(col / BLOCK), by = Math.floor(row / BLOCK)
        let best = Infinity, cls = classes[0]
        for (let j = by - 1; j <= by + 1; j++) for (let i = bx - 1; i <= bx + 1; i++) {
          const sx = (i + hash(i, j, seed, 2)) * BLOCK, sy = (j + hash(i, j, seed, 3)) * BLOCK
          const d = (sx - col - 0.5) ** 2 + (sy - row - 0.5) ** 2
          if (d < best) { best = d; cls = classes[Math.floor(hash(i, j, seed, 4) * K)] }
        }
        return cls
      }
    case 'noise': {
      const noise = makeNoise3D(seed)
      const feature = Math.max(1, cols / 4)
      const value = (col: number, row: number): number => {
        let v = 0, amp = 1, f = 1 / feature
        for (let o = 0; o < NOISE_OCTAVES; o++) { v += amp * noise(col * f, row * f, o * 17.3); f *= 2; amp *= NOISE_ROUGHNESS }
        return v
      }
      // Quantile cut over the INITIAL population: K−1 thresholds, baked into the closure.
      const n = cols * rows
      const sample = new Float32Array(n)
      for (let r = 0; r < rows; r++) for (let c = 0; c < cols; c++) sample[r * cols + c] = value(c, r)
      const sorted = Float32Array.from(sample).sort()
      const cuts: number[] = []
      for (let k = 1; k < K; k++) cuts.push(sorted[Math.min(n - 1, Math.floor((k * n) / K))])
      return (col, row) => {
        const v = value(col, row)
        let band = 0
        while (band < cuts.length && v >= cuts[band]) band++
        return classes[band]
      }
    }
  }
}

/** Evaluate a field over a grid. `out` may be reused; it is (re)allocated if the size differs. */
export function fillField(fn: FieldFn, cols: number, rows: number, out?: Uint8Array): Uint8Array {
  const n = cols * rows
  const g = out && out.length === n ? out : new Uint8Array(n)
  for (let r = 0; r < rows; r++) for (let c = 0; c < cols; c++) g[r * cols + c] = fn(c, r)
  return g
}
```

```ts
// src/diversions/waymark/step.ts
// The machine. Tiles are a Uint8Array of POINTERS into the program — never a colour —
// so the picture is always a pure function of (pointers, live config). Ants carry a clock
// `prog` that advances at `speed` cells per second: the ant sits on its tile for DWELL of
// a step, then hops. The commit is ATOMIC AT ARRIVAL (read the letter, advance the pointer,
// decide the turn); the colour tween that follows is display only, keyed by tile index.
import { mulberry32 } from '../../framework/rng'
import { HEAD, turn, type Letter } from './program'
import { makeField, fillField, type FieldFn, type FieldKind } from './field'

export const DWELL = 0.75
export const RENEW_AT = 0.6
export const FADE_MS = 4000

export type Lab = readonly [number, number, number]
export interface Ant { x: number; y: number; h: number; nx: number; ny: number; nh: number; prog: number }
export interface Tween { from: Lab; t: number }
export interface World {
  cols: number; rows: number; letters: Letter[]; n: number
  kind: FieldKind; seed: number; generation: number; field: FieldFn
  pointers: Uint8Array; start: Uint8Array; carved: number
  ants: Ant[]; tweens: Map<number, Tween>
  old: Uint8Array | null; fadeT: number
}
export interface WorldOpts { letters: Letter[]; kind: FieldKind; cols: number; rows: number; seed: number; ants: number }
export type LabOf = (pointer: number) => Lab

const GEN_SALT = 0x9e3779b1

export const ease = (t: number): number => (t < 0.5 ? 2 * t * t : 1 - Math.pow(-2 * t + 2, 2) / 2)

function placeAnt(w: World, i: number): Ant {
  const rng = mulberry32(((w.seed | 0) + Math.imul(w.generation, GEN_SALT) + Math.imul(i + 1, 0x85ebca6b)) | 0)
  const x = Math.floor(rng() * w.cols), y = Math.floor(rng() * w.rows), h = Math.floor(rng() * 4)
  return { x, y, h, nx: x, ny: y, nh: h, prog: 0 }
}

export function createWorld(o: WorldOpts): World {
  const n = o.letters.length
  const w: World = {
    cols: o.cols, rows: o.rows, letters: o.letters, n,
    kind: o.kind, seed: o.seed, generation: 0,
    field: makeField(o.kind, o.letters, o.cols, o.rows, o.seed),
    pointers: new Uint8Array(0), start: new Uint8Array(0), carved: 0,
    ants: [], tweens: new Map(), old: null, fadeT: 1,
  }
  w.pointers = fillField(w.field, w.cols, w.rows)
  w.start = w.pointers.slice()
  for (let i = 0; i < o.ants; i++) w.ants.push(placeAnt(w, i))
  // An ant "arrives" on its first tile immediately; the tween starts from the tile's own colour,
  // which the caller cannot supply yet — so use the identity: from = to (no visible change).
  for (const a of w.ants) arrive(w, a, (p) => rgbToLab([0, 0, 0]), true)
  return w
}

/** Read the letter, ADVANCE THE POINTER NOW, decide the turn and destination, start the tween. */
export function arrive(w: World, a: Ant, labOf: LabOf, silent = false): void {
  const k = a.y * w.cols + a.x
  const before = w.pointers[k]
  const letter = w.letters[before]
  const after = (before + 1) % w.n
  w.pointers[k] = after
  const s = w.start[k]
  if (before === s && after !== s) w.carved++
  else if (before !== s && after === s) w.carved--
  a.nh = turn(a.h, letter)
  a.nx = (a.x + HEAD[a.nh][0] + w.cols) % w.cols
  a.ny = (a.y + HEAD[a.nh][1] + w.rows) % w.rows
  if (!silent) {
    const cur = displayLab(w, k, labOf) ?? labOf(before)
    w.tweens.set(k, { from: cur, t: 0 })
  }
}

export function displayLab(w: World, idx: number, labOf: LabOf): Lab | null {
  const tw = w.tweens.get(idx)
  if (!tw) return null
  return lerpLab(tw.from, labOf(w.pointers[idx]), ease(tw.t))
}

export function tick(w: World, dtMs: number, speed: number, renewOn: boolean, labOf: LabOf): void {
  const dprog = (dtMs / 1000) * speed
  for (const a of w.ants) {
    a.prog += dprog
    while (a.prog >= 1) {
      a.prog -= 1
      a.x = a.nx; a.y = a.ny; a.h = a.nh
      arrive(w, a, labOf)
    }
  }
  // tweens run on the dwell's clock: a full tween lasts DWELL / speed seconds
  const dt = dprog / DWELL
  for (const [k, tw] of w.tweens) { tw.t += dt; if (tw.t >= 1) w.tweens.delete(k) }
  if (w.old) { w.fadeT += dtMs / FADE_MS; if (w.fadeT >= 1) { w.old = null; w.fadeT = 1 } }
  if (renewOn && shouldRenew(w)) renew(w)
}

export function antPos(w: World, a: Ant): [number, number] {
  if (a.prog < DWELL) return [a.x, a.y]
  const t = ease((a.prog - DWELL) / (1 - DWELL))
  let dx = a.nx - a.x, dy = a.ny - a.y
  if (dx > 1) dx -= w.cols; if (dx < -1) dx += w.cols
  if (dy > 1) dy -= w.rows; if (dy < -1) dy += w.rows
  return [a.x + dx * t, a.y + dy * t]
}

/** Heading angle in radians (E = 0, clockwise on screen), easing h → nh over the dwell by the short arc; D = +180. */
export function antAngle(a: Ant): number {
  const a0 = a.h * 90, a1 = a.nh * 90
  let d = ((((a1 - a0) % 360) + 540) % 360) - 180
  if (d === -180) d = 180
  return ((a0 + d * ease(Math.min(1, a.prog / DWELL))) * Math.PI) / 180
}

/** Height changed: extend or trim rows with the SAME field closure; keep ants; snap a mid-hop ant. */
export function resizeRows(w: World, rows: number): void {
  if (rows === w.rows) return
  const keep = Math.min(rows, w.rows)
  const p = new Uint8Array(w.cols * rows), s = new Uint8Array(w.cols * rows)
  p.set(w.pointers.subarray(0, w.cols * keep)); s.set(w.start.subarray(0, w.cols * keep))
  for (let r = keep; r < rows; r++) for (let c = 0; c < w.cols; c++) { const v = w.field(c, r); p[r * w.cols + c] = v; s[r * w.cols + c] = v }
  if (w.old) { const o = new Uint8Array(w.cols * rows); o.set(w.old.subarray(0, w.cols * keep)); for (let k = w.cols * keep; k < o.length; k++) o[k] = p[k]; w.old = o }
  w.pointers = p; w.start = s; w.rows = rows; w.n = w.cols * rows
  w.carved = 0; for (let k = 0; k < w.n; k++) if (p[k] !== s[k]) w.carved++
  w.tweens.clear()
  for (const a of w.ants) {
    if (a.prog >= DWELL) { a.x = a.nx; a.y = a.ny; a.h = a.nh; a.prog = 0 }
    a.y = Math.min(a.y, rows - 1)
    arrive(w, a, () => [0, 0, 0] as const, true)
  }
}

export function setAntCount(w: World, n: number): void {
  while (w.ants.length > n) w.ants.pop()
  while (w.ants.length < n) { const a = placeAnt(w, w.ants.length); w.ants.push(a); arrive(w, a, () => [0, 0, 0] as const, true) }
}

export function shouldRenew(w: World): boolean {
  return w.carved >= w.n * RENEW_AT
}

/** A fresh field of the same kind, next generation; the ants keep walking from where they are. */
export function renew(w: World): void {
  w.old = w.pointers.slice()
  w.fadeT = 0
  w.generation++
  w.field = makeField(w.kind, w.letters, w.cols, w.rows, (w.seed + Math.imul(w.generation, GEN_SALT)) | 0)
  w.pointers = fillField(w.field, w.cols, w.rows)
  w.start = w.pointers.slice()
  w.carved = 0
  w.tweens.clear()
}

// ---- OKLab (Björn Ottosson's matrices). sRGB in 0..255.
const toLin = (c: number) => { c /= 255; return c <= 0.04045 ? c / 12.92 : Math.pow((c + 0.055) / 1.055, 2.4) }
const toSrgb = (c: number) => { const v = c <= 0.0031308 ? 12.92 * c : 1.055 * Math.pow(Math.max(0, c), 1 / 2.4) - 0.055; return Math.max(0, Math.min(255, v * 255)) }

export function hexToRgb(hex: string): [number, number, number] {
  return [parseInt(hex.slice(1, 3), 16), parseInt(hex.slice(3, 5), 16), parseInt(hex.slice(5, 7), 16)]
}
export function rgbToLab(rgb: readonly [number, number, number]): Lab {
  const r = toLin(rgb[0]), g = toLin(rgb[1]), b = toLin(rgb[2])
  const l = Math.cbrt(0.4122214708 * r + 0.5363325363 * g + 0.0514459929 * b)
  const m = Math.cbrt(0.2119034982 * r + 0.6806995451 * g + 0.1073969566 * b)
  const s = Math.cbrt(0.0883024619 * r + 0.2817188376 * g + 0.6299787005 * b)
  return [0.2104542553 * l + 0.793617785 * m - 0.0040720468 * s, 1.9779984951 * l - 2.428592205 * m + 0.4505937099 * s, 0.0259040371 * l + 0.7827717662 * m - 0.808675766 * s]
}
export function labToRgb(lab: Lab): [number, number, number] {
  const l = lab[0] + 0.3963377774 * lab[1] + 0.2158037573 * lab[2]
  const m = lab[0] - 0.1055613458 * lab[1] - 0.0638541728 * lab[2]
  const s = lab[0] - 0.0894841775 * lab[1] - 1.291485548 * lab[2]
  const L = l * l * l, M = m * m * m, S = s * s * s
  return [toSrgb(4.0767416621 * L - 3.3077115913 * M + 0.2309699292 * S), toSrgb(-1.2684380046 * L + 2.6097574011 * M - 0.3413193965 * S), toSrgb(-0.0041960863 * L - 0.7034186147 * M + 1.707614701 * S)]
}
export function lerpLab(a: Lab, b: Lab, t: number): Lab {
```

```ts
// src/diversions/waymark/render.ts
// The only file that touches a context. Tiles are painted from a ≤ 4-entry style cache
// (one fillStyle per letter, rebuilt on a colour edit), so a live palette change recolours
// the whole field next frame; only the handful of tweening tiles build a colour per frame.
import { antAngle, antPos, displayLab, ease, hexToRgb, labToRgb, rgbToLab, type Lab, type World } from './step'
import type { Letter } from './program'

export interface Styles { style: string[]; lab: Lab[] }
export interface RenderOpts { width: number; height: number; background: string; antColor: string }
export type LetterColors = { colorL: string; colorR: string; colorU: string; colorD: string }

export function buildStyles(letters: Letter[], colors: LetterColors): Styles {
  const hex: Record<Letter, string> = { L: colors.colorL, R: colors.colorR, U: colors.colorU, D: colors.colorD }
  return { style: letters.map((L) => hex[L]), lab: letters.map((L) => rgbToLab(hexToRgb(hex[L]))) }
}

const gutter = (cell: number) => Math.max(1, Math.min(3, cell * 0.06))

function tiles(ctx: CanvasRenderingContext2D, w: World, grid: Uint8Array, styles: Styles, cell: number, gap: number, tween: boolean): void {
  const labOf = (p: number) => styles.lab[p]
  for (let r = 0; r < w.rows; r++) for (let c = 0; c < w.cols; c++) {
    const k = r * w.cols + c
    const lab = tween ? displayLab(w, k, labOf) : null
    if (lab) { const [R, G, B] = labToRgb(lab); ctx.fillStyle = `rgb(${R | 0},${G | 0},${B | 0})` }
    else ctx.fillStyle = styles.style[grid[k]]
    ctx.fillRect(c * cell + gap / 2, r * cell + gap / 2, cell - gap, cell - gap)
  }
}

export function render(ctx: CanvasRenderingContext2D, w: World, styles: Styles, o: RenderOpts): void {
  const cell = o.width / w.cols, gap = gutter(cell)
  ctx.fillStyle = o.background
  ctx.fillRect(0, 0, o.width, o.height)
  if (w.old) {
    tiles(ctx, w, w.old, styles, cell, gap, false)
    ctx.globalAlpha = ease(Math.min(1, w.fadeT))
    tiles(ctx, w, w.pointers, styles, cell, gap, true)
    ctx.globalAlpha = 1
  } else {
    tiles(ctx, w, w.pointers, styles, cell, gap, true)
  }
  // the ant: head dash on the leading edge, foot brackets on the trailing corners; rotates in
  // place over the dwell, glides with the ant over the hop
  const lw = Math.max(2.5, cell * 0.09), r = (cell - gap) / 2 - lw / 2, head = r * 0.5, arm = r * 0.6
  ctx.strokeStyle = o.antColor; ctx.lineWidth = lw; ctx.lineCap = 'butt'; ctx.lineJoin = 'miter'
  for (const a of w.ants) {
    const [ax, ay] = antPos(w, a)
    ctx.save()
    ctx.translate((ax + 0.5) * cell, (ay + 0.5) * cell)
    ctx.rotate(antAngle(a) + Math.PI / 2)              // marks are authored facing north
    ctx.beginPath()
    ctx.moveTo(-head, -r); ctx.lineTo(head, -r)
    ctx.moveTo(-r, r - arm); ctx.lineTo(-r, r); ctx.lineTo(-r + arm, r)
    ctx.moveTo(r, r - arm); ctx.lineTo(r, r); ctx.lineTo(r - arm, r)
    ctx.stroke()
    ctx.restore()
  }
}
```

```ts
import { defineDiversion, type PresetGroup, type Size } from '../../framework/types'
import { waymarkSchema, type WaymarkConfig } from './schema'
import { parseProgram } from './program'
import { createWorld, tick, resizeRows, setAntCount, type World } from './step'
import { buildStyles, render, type Styles } from './render'
import { programPresets, palettePresets } from './presets'
import { meta } from './meta'

interface State { cfg: WaymarkConfig; world: World; styles: Styles; size: Size }

const STRUCTURAL: (keyof WaymarkConfig)[] = ['program', 'field', 'columns', 'seed']

const rowsFor = (cfg: WaymarkConfig, size: Size): number => {
  const cols = Number(cfg.columns)
  return Math.max(1, Math.round(size.height / (size.width / cols)))
}

const presets: PresetGroup<WaymarkConfig>[] = [
  { label: 'Program', options: programPresets },
  { label: 'Palette', options: palettePresets },
]

const waymark = defineDiversion<typeof waymarkSchema, State, '2d'>({
  ...meta,
  schema: waymarkSchema,

  setup(_ctx, cfg, size) {
    const letters = parseProgram(cfg.program)
    const world = createWorld({ letters, kind: cfg.field, cols: Number(cfg.columns), rows: rowsFor(cfg, size), seed: cfg.seed, ants: cfg.ants })
    return { cfg, world, styles: buildStyles(letters, cfg.colors), size }
  },

  frame(state, ctx, _t, dt) {
    // dt is MILLISECONDS (clamped at 50 ms); tick converts.
    const { world, styles, cfg } = state
    tick(world, dt, cfg.speed, cfg.renew, (p) => styles.lab[p])
    render(ctx, world, styles, { width: state.size.width, height: state.size.height, background: cfg.background, antColor: cfg.antColor })
  },

  resize(state, size) {
    // Columns are fixed by config; only the row count follows the aspect. The field's
    // closure evaluates the new rows; existing rows and every ant are kept.
    state.size = size
    resizeRows(state.world, rowsFor(state.cfg, size))
  },

  update(state, cfg) {
    const prev = state.cfg
    if (STRUCTURAL.some((k) => cfg[k] !== prev[k])) return false
    if (cfg.ants !== prev.ants) setAntCount(state.world, cfg.ants)
    const colorsChanged = (Object.keys(cfg.colors) as (keyof typeof cfg.colors)[]).some((k) => cfg.colors[k] !== prev.colors[k])
    if (colorsChanged) state.styles = buildStyles(state.world.letters, cfg.colors)
    state.cfg = cfg
    return true
  },

  presets,
})

export default waymark
```
