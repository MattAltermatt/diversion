# BoxCar2D Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `boxcar2d` — a deterministic, ambient diversion where a genetic algorithm evolves 2D cars (Box2D v3 physics) over a fixed hilly track, run solo car-by-car, visibly improving generation over generation.

**Architecture:** A typed seam over `phaser-box2d` (standalone, no Phaser) does all rigid-body work. Pure, rng-driven modules handle the genome and GA. The diversion's `setup/frame/update/teardown` drives a small state machine (current car → next car → breed next generation) on a seed-fixed track, drawing chassis/wheels/terrain/flag/HUD to the 2D canvas itself. Everything random flows through `framework/rng.ts(seed)` so a URL seed reproduces the whole multi-generation run.

**Tech Stack:** Vite + React 19 + TypeScript + Zod 4 · `phaser-box2d` (Box2D v3.0, deep-import `phaser-box2d/dist/PhaserBox2D.js`) · Vitest.

## Global Constraints

- **Engine:** `phaser-box2d` imported as `phaser-box2d/dist/PhaserBox2D.js` (broken `main`/no `exports` map — bare import fails). Pure JS, synchronous init. Untyped → all engine access behind the typed `physics.ts` seam; never leak `any` into the diversion.
- **Determinism (keystone):** ALL randomness via `mulberry32(config.seed)` from `src/framework/rng.ts` (track, genomes, selection, mutation). Box2D adds no randomness. Fixed timestep `1/60 s` via accumulator; each car simulates a FIXED step budget so fitness is render-speed-independent. `speed` only changes steps drawn per frame, never the outcome.
- **Contract:** `defineDiversion` from `src/framework/types.ts`; `kind: '2d'`; `setup(ctx, config, size)` is SYNCHRONOUS; `frame(state, ctx, t, dt)` (dt in ms, clamped ≤50). `ctx` is a DPR-scaled `CanvasRenderingContext2D` — draw in CSS px.

- **Coordinate convention:** Box2D is meters, Y-up; canvas is px, Y-down. Centralize px↔m + Y-flip in the seam (mirror asteroid-miner: `getBodyPosition` returns `{x: p.x*SCALE, y: -p.y*SCALE}`, `getBodyAngle` returns `-atan2(r.s, r.c)`).

```ts
// genome.ts
export const N_VERTICES = 8
export const N_WHEELS = 2

export interface Wheel { present: boolean; vertex: number; radius: number; density: number }
export interface Genome { mags: number[]; chassisDensity: number; wheels: Wheel[] }

export interface GenomeRanges {
  magMin: number; magMax: number
  densMin: number; densMax: number
  wheelRMin: number; wheelRMax: number
  wheelDensMin: number; wheelDensMax: number
}

// 🎚️ tunable defaults (meters / density). Sane starting point; tune in Chrome.
export const DEFAULT_RANGES: GenomeRanges = {
  magMin: 0.3, magMax: 1.1,
  densMin: 0.5, densMax: 3,
  wheelRMin: 0.2, wheelRMax: 0.5,
  wheelDensMin: 0.5, wheelDensMax: 2,
}

const lerp = (a: number, b: number, t: number) => a + (b - a) * t

export function randomGenome(rng: () => number, r: GenomeRanges = DEFAULT_RANGES): Genome {
  const mags = Array.from({ length: N_VERTICES }, () => lerp(r.magMin, r.magMax, rng()))
  const chassisDensity = lerp(r.densMin, r.densMax, rng())
  const wheels: Wheel[] = Array.from({ length: N_WHEELS }, () => ({
    present: rng() < 0.85, // mostly-present; lets 1-wheel cars appear
    vertex: Math.floor(rng() * N_VERTICES),
    radius: lerp(r.wheelRMin, r.wheelRMax, rng()),
    density: lerp(r.wheelDensMin, r.wheelDensMax, rng()),
  }))
  return { mags, chassisDensity, wheels }
}
```

```ts
const clamp = (v: number, lo: number, hi: number) => Math.min(hi, Math.max(lo, v))

export function crossover(a: Genome, b: Genome, rng: () => number): Genome {
  const pick = <T>(x: T, y: T) => (rng() < 0.5 ? x : y)
  return {
    mags: a.mags.map((m, i) => pick(m, b.mags[i])),
    chassisDensity: pick(a.chassisDensity, b.chassisDensity),
    wheels: a.wheels.map((w, i) => ({
      present: pick(w.present, b.wheels[i].present),
      vertex: pick(w.vertex, b.wheels[i].vertex),
      radius: pick(w.radius, b.wheels[i].radius),
      density: pick(w.density, b.wheels[i].density),
    })),
  }
}

export function mutate(g: Genome, rate: number, rng: () => number, r: GenomeRanges = DEFAULT_RANGES): Genome {
  // jitter as a fraction of the gene's range when the per-gene roll fires
  const jit = (v: number, lo: number, hi: number) =>
    rng() < rate ? clamp(v + (rng() * 2 - 1) * (hi - lo) * 0.25, lo, hi) : v
  return {
    mags: g.mags.map(m => jit(m, r.magMin, r.magMax)),
    chassisDensity: jit(g.chassisDensity, r.densMin, r.densMax),
    wheels: g.wheels.map(w => ({
      present: rng() < rate ? !w.present : w.present,
      vertex: rng() < rate ? Math.floor(rng() * N_VERTICES) : w.vertex,
      radius: jit(w.radius, r.wheelRMin, r.wheelRMax),
      density: jit(w.density, r.wheelDensMin, r.wheelDensMax),
    })),
  }
}
```

> Note: the `rate 0` test passes because every `rng() < 0` is false, so each gene returns its original value unchanged.

```ts
// ga.ts
import { type Genome, crossover, mutate, type GenomeRanges } from './genome'

export interface Scored { genome: Genome; fitness: number }

const EPS = 1e-6

export function roulettePick(scored: Scored[], rng: () => number): Genome {
  const total = scored.reduce((s, x) => s + Math.max(EPS, x.fitness), 0)
  let r = rng() * total
  for (const x of scored) {
    r -= Math.max(EPS, x.fitness)
    if (r <= 0) return x.genome
  }
  return scored[scored.length - 1].genome
}

export function breedGeneration(
  scored: Scored[],
  opts: { eliteCount: number; mutationRate: number; ranges: GenomeRanges },
  rng: () => number,
): Genome[] {
  const ranked = [...scored].sort((a, b) => b.fitness - a.fitness)
  const size = ranked.length
  const elite = Math.min(opts.eliteCount, size)
  const next: Genome[] = ranked.slice(0, elite).map(s => s.genome)
  while (next.length < size) {
    const a = roulettePick(ranked, rng)
    const b = roulettePick(ranked, rng)
    next.push(mutate(crossover(a, b, rng), opts.mutationRate, rng, opts.ranges))
  }
  return next
}
```

```ts
// terrain.ts
import type { Vec2 } from './physics'

export interface TerrainOpts { segments: number; segLen: number; roughness: number; startFlat: number }

export function generateTerrain(rng: () => number, opts: TerrainOpts): Vec2[] {
  const pts: Vec2[] = []
  let y = 0
  let slope = 0
  for (let i = 0; i <= opts.segments; i++) {
    if (i <= opts.startFlat) {
      pts.push({ x: i * opts.segLen, y: 0 }) // flat launch ramp
      continue
    }
    // random-walk the slope for smooth rolling hills (not spiky noise)
    slope += (rng() * 2 - 1) * opts.roughness
    slope = Math.max(-1.2, Math.min(1.2, slope))
    y += slope
```

```ts
import {
  createWorld, destroyWorld, stepWorld, buildTerrainBody,
  createPolygonBody, createCircleBody, createWheelJoint,
  getBodyPosition, getBodyLinearVelocityX, SCALE, type WorldId, type BodyId, type Vec2,
} from './physics'
import { type Genome, N_VERTICES } from './genome'

export const CAR_GROUP = -1

export interface CarBodies { chassis: BodyId; wheels: { body: BodyId; radius: number }[] }
export interface SimCfg {
  gravity: number; maxSteps: number; stallSteps: number; stallVx: number
  motorSpeed: number; motorTorque: number; spawnX: number; spawnY: number
}
export interface SimResult { fitness: number }

export function chassisVertices(g: Genome): Vec2[] {
  return g.mags.map((m, k) => {
    const a = (k / N_VERTICES) * Math.PI * 2
    return { x: Math.cos(a) * m, y: Math.sin(a) * m }
  })
}

export function buildCar(worldId: WorldId, g: Genome, spawn: Vec2, motor: { speed: number; torque: number }): CarBodies {
  const verts = chassisVertices(g)
  const chassis = createPolygonBody(worldId, {
    position: { x: spawn.x * SCALE, y: spawn.y * SCALE }, // physics seam takes px
    vertices: verts, density: g.chassisDensity, friction: 0.4, groupIndex: CAR_GROUP,
  })
  const wheels: { body: BodyId; radius: number }[] = []
  for (const w of g.wheels) {
    if (!w.present) continue
    const v = verts[w.vertex]
    const wheelPos: Vec2 = { x: (spawn.x + v.x) * SCALE, y: (spawn.y + v.y) * SCALE }
    const body = createCircleBody(worldId, {
      position: wheelPos, radius: w.radius, density: w.density, friction: 1.0, groupIndex: CAR_GROUP,
    })
    createWheelJoint(worldId, {
      chassis, wheel: body, anchor: wheelPos, axisX: 0, axisY: 1,
      enableMotor: true, motorSpeed: -motor.speed, maxMotorTorque: motor.torque,
      enableSpring: true, hertz: 4, dampingRatio: 0.7,
    })
    wheels.push({ body, radius: w.radius })
  }
  return { chassis, wheels }
}

export function simulateCar(g: Genome, terrain: Vec2[], cfg: SimCfg): SimResult {
  const world = createWorld(cfg.gravity)
  buildTerrainBody(world, terrain)
  const car = buildCar(world, g, { x: cfg.spawnX, y: cfg.spawnY }, { speed: cfg.motorSpeed, torque: cfg.motorTorque })
  let maxX = cfg.spawnX
  let stall = 0
  for (let i = 0; i < cfg.maxSteps; i++) {
    stepWorld(world, 1)
    const px = getBodyPosition(car.chassis).x / SCALE // back to meters
    if (px > maxX) maxX = px
    if (Math.abs(getBodyLinearVelocityX(car.chassis)) < cfg.stallVx) {
      if (++stall >= cfg.stallSteps) break
    } else stall = 0
  }
  destroyWorld(world) // frees all bodies/joints — no leak
  return { fitness: Math.max(0, maxX - cfg.spawnX) }
}
```

> Determinism: each car runs in a fresh world for a fixed step count with no randomness inside the loop, so identical inputs give identical `maxX`.

```ts
// render.ts (shape — fill in against the live State type from Task 10)
import { getBodyPosition, getBodyAngle, SCALE } from './physics'
import { chassisVertices } from './car'
import type { BoxCarState } from './index'

export function drawScene(ctx: CanvasRenderingContext2D, s: BoxCarState): void {
  const { width, height } = s.size
  // sky gradient
  const sky = ctx.createLinearGradient(0, 0, 0, height)
  sky.addColorStop(0, s.cfg.color.sky); sky.addColorStop(1, '#000')
  ctx.fillStyle = sky; ctx.fillRect(0, 0, width, height)

  // camera follows current chassis (lerp)
  const carPx = getBodyPosition(s.current.chassis)
  s.camX += (carPx.x - width * 0.35 - s.camX) * 0.08
  const camY = height * 0.6
  const toScreen = (px: number, py: number) => ({ x: px - s.camX, y: camY + py })

  // terrain fill + line
  ctx.beginPath()
  s.terrain.forEach((p, i) => {
    const sx = p.x * SCALE - s.camX, sy = camY - p.y * SCALE
    i ? ctx.lineTo(sx, sy) : ctx.moveTo(sx, sy)
  })
  ctx.lineTo(s.terrain[s.terrain.length - 1].x * SCALE - s.camX, height)
  ctx.lineTo(s.terrain[0].x * SCALE - s.camX, height); ctx.closePath()
  ctx.fillStyle = s.cfg.color.terrain; ctx.fill()

  // record flag
  const flagX = s.bestDistMeters * SCALE - s.camX
  ctx.strokeStyle = '#fff'; ctx.beginPath(); ctx.moveTo(flagX, 0); ctx.lineTo(flagX, height); ctx.stroke()

  // current car: chassis polygon + wheels with hub spoke
  const cp = getBodyPosition(s.current.chassis), ca = getBodyAngle(s.current.chassis)
  ctx.save(); ctx.translate(cp.x - s.camX, camY + cp.y); ctx.rotate(ca)
  const verts = chassisVertices(s.current.genome)
  ctx.beginPath(); verts.forEach((v, i) => (i ? ctx.lineTo(v.x * SCALE, -v.y * SCALE) : ctx.moveTo(v.x * SCALE, -v.y * SCALE)))
  ctx.closePath(); ctx.fillStyle = s.cfg.color.chassis; ctx.fill(); ctx.restore()
  for (const w of s.current.wheels) {
    const wp = getBodyPosition(w.body), wa = getBodyAngle(w.body), r = w.radius * SCALE
    ctx.save(); ctx.translate(wp.x - s.camX, camY + wp.y); ctx.rotate(wa)
    ctx.fillStyle = s.cfg.color.wheel; ctx.beginPath(); ctx.arc(0, 0, r, 0, Math.PI * 2); ctx.fill()
    ctx.strokeStyle = '#fff'; ctx.beginPath(); ctx.moveTo(0, 0); ctx.lineTo(r, 0); ctx.stroke() // spoke → spin visible
    ctx.restore()
  }

  if (s.cfg.showHud) {
    ctx.fillStyle = '#fff'; ctx.font = '14px system-ui'
    ctx.fillText(`Gen ${s.generation} · Car ${s.carIndex + 1}/${s.cfg.population} · Dist ${(getBodyPosition(s.current.chassis).x / SCALE - s.spawnX).toFixed(1)}m · Best ${s.bestDistMeters.toFixed(1)}m`, 12, 22)
  }
}
```

### Task 10: Diversion wiring — state machine + lifecycle (INLINE)

**Files:** Create: `src/diversions/boxcar2d/index.ts`, `src/diversions/boxcar2d/index.test.ts`

**Interfaces:**

- Produces: `export interface BoxCarState { ... }` (used by `render.ts`); `export default` the diversion.
  - `BoxCarState` fields: `cfg, size, world, terrain (Vec2[] meters), population (Genome[]), scored (Scored[]), carIndex, generation, current (CarBodies & { genome }), camX, bestDistMeters, spawnX, stepsThisCar, stallCounter, rng (the GA rng, persisted across generations)`

**Behavior (the state machine, advanced inside `frame`):**
- `setup`: `rng = mulberry32(seed)`; `terrain = generateTerrain(mulberry32(seed))`; `population = Array.from({length}, () => randomGenome(rng))`; build world + spawn car 0; init `bestDistMeters = 0`, `generation = 1`, `carIndex = 0`.
- `frame`: run `cfg.speed` fixed steps (`stepWorld(world, 1)` each, tracking max-x + stall). On car end (stall/timeout/end-of-track): record `scored[carIndex]`, update `bestDistMeters`, destroy current car bodies, `carIndex++`. If `carIndex >= population`: `population = breedGeneration(scored, opts, rng)`; `generation++`; if `generation % trackLifespan === 0` regenerate terrain from `rng` (so the new track is part of the deterministic stream); reset `carIndex=0`, `scored=[]`. Spawn the next car. Then `drawScene(ctx, state)`.
- `update`: live-apply `color`, `showHud`, `speed`, `motorTorque/Speed` (store on `cfg`; new torque/speed take effect on next car build) → return `true`. For `seed`/`population`/`roughness`/`trackLifespan`/`eliteCount`/`mutationRate` changes that alter the run structure → return `false` (host re-runs `setup`). Simpler safe default acceptable: live-apply only `color`+`showHud`+`speed`, return false otherwise.
- `teardown`: `destroyWorld(state.world)` (frees all bodies/joints) — the leak guard.
