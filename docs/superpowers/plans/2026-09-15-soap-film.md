# Soap Film Implementation Plan (#363)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `soap-film`, a full-frame draining soap film whose every colour is the computed reflectance of the film at that thickness — no palette exists anywhere in the piece.

**Architecture:** The thickness field is a **CPU** simulation on a fixed-count grid (vorticity–streamfunction fluid + marginal-regeneration nucleation + a conservative Poiseuille flux). Each frame it is uploaded into a persistent **`R16F`** texture with `texSubImage2D` from a reused `Float32Array`, and **one fullscreen-triangle fragment shader** turns thickness into colour by sampling a **baked 1-D `RGBA16F` LUT** built on the CPU from the spectral reflectance integral. The CPU/GPU split is deliberate: the sim measures **3.06 ms/step at 256×160 in bare Node** (the mockup's in-browser figure of 1.4 ms is the same code under a warmer JIT — quote the slower one), so moving it to the GPU would buy little and would cost a Jacobi Poisson solve as 20–40 extra passes per frame — and keeping it on the CPU keeps it unit-testable, which is what catches this piece's silent failure modes.

**Tech Stack:** Vite + React 19 + TypeScript + Zod 4 + WebGL2, Vitest.

**Spec:** `docs/superpowers/specs/2026-09-15-soap-film-design.md`

### Must-fixes folded in

1. **Task 0's closed-form colour is deleted; the LUT ships.** The `sensitivityFilmColor`
   written in the draft returns a **constant at every thickness** — verified. Four
   independent defects: the harmonic amplitude used `dcR` where the derivation gives
   `(1−dcR)` (24× too small, confirmed numerically against a direct Fourier transform
   of the Airy function); the harmonic ran at half the right frequency; the sensitivity
   table assigned Belcour's X/Y/Z lobe positions all to red and half its constants are
   unsourceable; and the normalisation was a fudge. Its own guard test missed all of it
   by 0.004. **The approved mockup was already a 2048-entry LUT indexed by optical
   thickness** — the draft's "fallback" was the working design all along. The LUT is
   provably the reference because it *is* the reference, and it deletes `highp`, the
   1e-13 amplitude hazard and the whole testable-twin apparatus.
2. **`R16F` for the thickness texture, per the spec, not `R32F`.** `R32F` + `LINEAR`
   silently returns **zero** without `OES_texture_float_linear` (this repo's own
   recorded gotcha, and `caustics/gl.ts` carries the comment). `R16F` is filterable in
   core WebGL2. The draft traded the spec's better choice for a fallback it then had to
   write. Same reasoning applies to the colour LUT: `RGBA16F`, normalised to peak 1.
3. **`meta.ts` moves out of Task 3 into the GL task.** `contract.test.ts:24` asserts
   every folder has **both** `meta.ts` and `index.ts`; a task that creates one without
   the other turns the suite red and its commit would violate this plan's own Global
   Constraint that `npm test` is green at every commit.
4. **Segmented and select values ship capitalised.** `Segmented` renders the *value*,
   not a label (`fieldMeta.ts` says a value/label split there "would be a lie"), so
   `'dilated' | 'slow' | 'none'` would print lowercase in the UI. `'Dilated' | 'Slow' |
   'None'`, and the same for `gridDetail`. This changes URL values, so it is not an
   execution-time tweak.
5. **Allocate the texture with `texImage2D`, never `texStorage2D`.** `makeGLContext()`
   in `src/test-setup.ts` has no `texStorage2D` and no `R32F` constant, and
   `diversionSmoke.test.ts` sweeps **every** diversion through it with zero exemptions
   — the idiomatic immutable-storage path would throw for the whole gallery.
6. **`tempo` scales `stepFilm`'s dt; the `clock` accumulator is deleted.** The draft
   copied the tempo idiom from a *time-driven* piece and wrote `state.clock += …` that
   nothing read, leaving `tempo` wired to nothing and a dead store that
   `--deny-warnings` would likely catch.
7. **`stepFilm` substeps internally.** `dt` is clamped at 50 ms and `tempo` reaches 6×,
   so the real `dtSeconds` reaches **0.30 s** — six times the largest value the draft's
   CFL test probed, and past the point where the smoothing term saturates its own clamp
   and framerate independence is gone. `stepFilm` now splits any `dtSeconds` above
   `MAX_SUBSTEP = 0.02` into equal substeps.
8. **`mobility` interpolates the Poiseuille constant too.** The mockup's mode toggle
   switches *three* things — buoyancy, nucleation rate, **and** the drain coefficient
   (0.024 marginal vs 0.060 rigid). The draft mapped two, so `mobility = 0` would have
   drained 2.5× too slowly in exactly the regime the `Rigid` preset depends on, and no
   test would have seen it.
9. **The piece must open in colour.** Measured on the mockup: mean saturation is **0.241
   at t = 0** — which *is* the >1500 nm asymptote — and takes **~100 s** to reach half
   saturation. Since `seed` is `randomizeOnFreshLoad`, nobody ever lands mid-cycle;
   every visit and every share link opens on that flat pink-grey. `filmThickness` now
   defaults into the coloured orders, and Task 1 carries a test asserting mean
   saturation at `t = 0` is already above the asymptote.
10. **The rupture gate must be reachable.** Measured over 90 simulated minutes, the
    peak black fraction was **10.9%** and **7.9%** in two cycles against a **12%** gate —
    it fired twice, both times on a noise excursion. Coarser grids have larger
    excursions, so `gridDetail` would change the ending's frequency from the same seed.
    The gate is now *reachable by construction*: nucleate once black film exists at all
    **and** the film's mean has fallen below a fraction of its formation thickness,
    with a hard ceiling on film age. Task 2 asserts a rupture occurs within a bounded
    time across several seeds **and** both grid settings.
11. **Re-forming fades rather than snaps.** The mockup's `formFilm()` cuts instantly
    back to a flat field, which in a calm piece is a hard cut every cycle.

### Accepted risks — the naysayer's objections we are NOT fixing

1. **"Computed, not chosen is provenance, not an image — a viewer cannot see it, and
   `foam` already ships a hand-picked four-stop palette literally named Soap Film."**
   Cheaper alternative: pick a gradient and skip the physics entirely. Rejected because
   the property the physics buys is not the four hues, it is **desaturation with order** —
   twenty fringes that read as twenty *different* fringes rather than a repeating
   rainbow. A four-stop palette cannot do that, and the LUT gets it for free. The
   provenance claim in the spec's opening is being toned down accordingly; the *visual*
   claim is the one being made.
2. **"A full-frame pastel field is hard to tell from `paper-marbling` / `cwaves` /
   `swirl`."** Cheaper alternative: the stratified still, which nothing here does.
   Rejected **by the owner, explicitly**, after viewing both against a photograph: the
   stratified image does not move, and this gallery ships motion. The residual risk —
   that the swirling film reads as a recolour — is real and is accepted with eyes open.
3. **"Five chosen colours sit in a piece whose thesis is that nothing is chosen"**
   (`background`, `exposure`, `filmIndex`, `illuminant`, the rupture rim). Cheaper
   alternative: drop the thesis and add a palette. Rejected: `background` is seen only
   through the rupture, `exposure` compensates a film that really does reflect ~8%, and
   `filmIndex` moves the *whole* series coherently, which is the physical behaviour.
   But the spec's absolute phrasing overstates it and is being softened.

### Task 0: The colour model — `optics.ts` (LUT, not a closed form)

This is the keystone. If the colour is wrong the piece has no reason to exist, and the
draft's closed form failed silently in a way six of seven numeric assertions missed.
**Do not reintroduce a closed form.** See Revision 1 item 1.

**Files:**
- Create: `src/diversions/soap-film/optics.ts`
- Test: `src/diversions/soap-film/optics.test.ts`

**Interfaces:**
- Consumes: nothing.
- Produces:
  - `export interface Rgb { r: number; g: number; b: number }` — **linear** sRGB 0..1, LUT-normalised to peak luminance 1.
  - `export type IlluminantName = 'Daylight' | 'Overcast' | 'Tungsten' | 'Studio'` — **capitalised**, because `select`/`segmented` render the value.
  - `export const LUT_N: number` — 2048. `export const LUT_MAX_OPD: number` — 5200 nm of **optical** thickness.
  - `export function spectralFilmColor(opdNm: number, filmIndex: number): Rgb` — the reference integral, unnormalised.
  - `export function buildColorLut(filmIndex: number, illuminant: IlluminantName): Float32Array` — `LUT_N * 4` RGBA, peak-normalised, ready for `texImage2D`.
  - `export function sampleLut(lut: Float32Array, opdNm: number): Rgb` — the CPU twin of the shader's texture fetch, for tests only.

**Why the LUT is indexed by OPTICAL thickness `n·d·cos θₜ`:** one table then serves every
viewing angle, and a future curved-film variant needs no second table. The mockup already
does this.

```ts
import { describe, expect, it } from 'vitest'
import { buildColorLut, LUT_MAX_OPD, sampleLut, spectralFilmColor, type Rgb } from './optics'

const N = 1.33
const lum = (c: Rgb) => 0.2126 * c.r + 0.7152 * c.g + 0.0722 * c.b
const sat = (c: Rgb) => {
  const mx = Math.max(c.r, c.g, c.b), mn = Math.min(c.r, c.g, c.b)
  return mx <= 0 ? 0 : (mx - mn) / mx
}
/** Hue angle in degrees, 0 = red, 120 = green, 240 = blue. Classifying by angle
 *  rather than by "which primary is largest" — a real first-order magenta film has
 *  b > r, so a max-channel test can never reach the colour it is named after. */
function hueDeg(c: Rgb) {
  const a = c.r - 0.5 * (c.g + c.b)
  const b = (Math.sqrt(3) / 2) * (c.g - c.b)
  return ((Math.atan2(b, a) * 180) / Math.PI + 360) % 360
}
const chroma = (c: Rgb) => { const s = c.r + c.g + c.b; return s === 0 ? [0, 0] : [c.r / s, c.g / s] }

describe('thin-film colour', () => {
  it('goes to black as the film vanishes — Newton black film', () => {
    // The piece's closing image. The half-wave phase shift at the first surface is
    // what makes it black; drop the shift and a zero-thickness film is BRIGHT,
    // which inverts the ending.
    expect(lum(spectralFilmColor(0, N))).toBeLessThan(1e-6)
    expect(lum(spectralFilmColor(7, N))).toBeLessThan(0.002)
    expect(lum(spectralFilmColor(40, N))).toBeLessThan(0.02)
    expect(lum(spectralFilmColor(160, N))).toBeGreaterThan(0.05)
  })

  it('washes out ABOVE 1500 nm to a fixed low level, not to a vivid band', () => {
    // THE anti-regression test, and the level is what makes it bite. A three-cosine
    // approximation lands at sat 0.155 against the truth's 0.157 — indistinguishable.
    // Its LUMINANCE sits at 0.50 against the truth's 0.039, a 13x separation.
    for (const opd of [1600, 2400, 4000, 10_000]) {
      const c = spectralFilmColor(opd, N)
      expect(sat(c)).toBeLessThan(0.35)
      expect(lum(c)).toBeGreaterThan(0.03)
      expect(lum(c)).toBeLessThan(0.05)
    }
  })

  it('is vividly coloured in the first orders', () => {
    expect(sat(spectralFilmColor(265, N))).toBeGreaterThan(0.55)
    expect(sat(spectralFilmColor(400, N))).toBeGreaterThan(0.35)
  })

  it('walks the Newton series in the published hue order', () => {
    // straw -> magenta -> blue -> green -> gold, by hue ANGLE.
    const h = (opd: number) => hueDeg(spectralFilmColor(opd, N))
    expect(h(265)).toBeGreaterThan(260)   // magenta/violet
    expect(h(330)).toBeGreaterThan(180)   // blue
    expect(h(330)).toBeLessThan(260)
    expect(h(400)).toBeGreaterThan(70)    // green
    expect(h(400)).toBeLessThan(180)
  })

  it('the LUT reproduces the integral it was built from', () => {
    const lut = buildColorLut(N, 'Daylight')
    for (let opd = 0; opd <= LUT_MAX_OPD; opd += 37) {
      const ref = spectralFilmColor(opd, N)
      const got = sampleLut(lut, opd)
      // the LUT is peak-normalised, so compare CHROMATICITY, which normalisation
      // leaves alone, plus a scaled luminance
      const [rx, ry] = chroma(ref), [gx, gy] = chroma(got)
      if (lum(ref) > 0.005) {
        expect(Math.abs(rx - gx)).toBeLessThan(0.02)
        expect(Math.abs(ry - gy)).toBeLessThan(0.02)
      }
    }
  })

  it('the LUT is not constant — it varies across thickness', () => {
    // The cheapest possible guard against the defect that killed the draft: a colour
    // function that ignores its own argument passed six of seven assertions.
    const lut = buildColorLut(N, 'Daylight')
    const seen = new Set<string>()
    for (let opd = 0; opd <= 1600; opd += 20) {
      const c = sampleLut(lut, opd)
      seen.add(`${c.r.toFixed(2)},${c.g.toFixed(2)},${c.b.toFixed(2)}`)
    }
    expect(seen.size).toBeGreaterThan(25)
  })

  it('illuminant actually changes the colour', () => {
    // It is the piece's only colour axis. The draft declared it and wired it to
    // nothing, which would have shipped four options that all look the same.
    const day = sampleLut(buildColorLut(N, 'Daylight'), 400)
    const tun = sampleLut(buildColorLut(N, 'Tungsten'), 400)
    const [dx, dy] = chroma(day), [tx, ty] = chroma(tun)
    expect(Math.hypot(dx - tx, dy - ty)).toBeGreaterThan(0.02)
  })

  it('never returns NaN', () => {
    for (const opd of [0, 1e-9, 1, 500, 1e5]) {
      const c = spectralFilmColor(opd, N)
      expect(Number.isFinite(c.r + c.g + c.b)).toBe(true)
    }
  })
})
```

```ts
/** Thickness -> colour for a symmetric air-film-air layer, as a baked LUT.
 *
 *  R(lambda) = 4R1 sin^2(delta/2) / ((1-R1)^2 + 4R1 sin^2(delta/2)),  delta = 4*pi*opd/lambda
 *
 *  ⚠️ NO CLOSED FORM. A Belcour-style sensitivity series was specified here first and
 *  returned a CONSTANT at every thickness — four independent defects, and the guard
 *  test written for it missed them by 0.004. The LUT is provably the reference because
 *  it IS the reference: 2048 entries over optical thickness, built by the integral
 *  below, uploaded once as RGBA16F. It also removes the need for `highp` and for the
 *  1e-13-amplitude hazard the closed form carried.
 *
 *  ⚠️ At a soap film's R1 (0.0201 at n = 1.33) the Airy series' SECOND harmonic is 50x
 *  smaller than the first, so multiple-beam Airy and a two-beam cosine are visually
 *  identical here. The objection to the cheap approximation is NOT two-beam vs Airy —
 *  it is integrating over wavelength versus sampling three of them. */
```

- CIE observer: the Wyman/Sloan/Shirley piecewise-Gaussian fit, 380–780 nm at 4 nm.
- Illuminant: von Kries scaling applied **during the LUT build**, so a perfect mirror maps
  to that illuminant's white point. `ILLUMINANT_XYZ` values as in the draft, keys capitalised.
- **Peak-normalise the built LUT to luminance 1** — a real film reflects ~8%, and the
  mockup's approved look divides by its own peak (a 10.2× multiplier) before `exposure`.
  The draft dropped both this and the D65 adaptation, which would have shipped a piece
  ~10× darker and measurably pinker than the capture the owner approved.
- `sampleLut` does the same bilinear fetch the shader does, so a test can stand where the
  GPU stands.

 *  takes ~10 s. Thin patches nucleate at the bottom and side Plateau borders and,

 *  smoothing term saturates its own clamp and framerate independence is gone, so split
 *  the step rather than trusting the clamps. */
export const MAX_SUBSTEP = 0.02
export function stepFilm(f: Film, p: FilmParams, dtSeconds: number): void {
  const n = Math.max(1, Math.ceil(dtSeconds / MAX_SUBSTEP))
  for (let i = 0; i < n; i++) subStep(f, p, dtSeconds / n)
}

// Gravity is NOT a velocity: as one it slides the field down, clamps at the bottom and
// FLATTENS the gradient instead of steepening it. It belongs in the conservative flux.

// The CFL cap. An unclamped q can exceed a cell's whole contents in one step.
const cap = 0.2 * h[i]; if (q > cap) q = cap
if (!(h[i] > 0.5)) h[i] = 0.5            // also catches NaN

const sm = Math.min(0.20, 0.40 * dtSeconds)

const buoy = 58 * p.mobility
const nucRate = 24 * p.mobility

- [ ] **Step 3: Write `gl.ts`**

One fullscreen triangle. `initGL` compiles the program, creates the empty VAO (WebGL2
wants one bound even for attributeless draws), creates the **`R16F`** thickness texture
and the **`RGBA16F`** 1-D colour LUT with `LINEAR` + `CLAMP_TO_EDGE`, and allocates the
reused `Float32Array`. Model on `caustics/gl.ts`'s `initGL`/`makeTex`/`disposeGL` and
`galaxy-collision/gl.ts:196`'s `uploadPositions`.

```ts
/** R16F, never R32F: float32 textures are NOT filterable in core WebGL2, so a LINEAR
 *  sampler over R32F silently returns 0 unless OES_texture_float_linear is present —
 *  this repo's own recorded gotcha. R16F needs no extension. Same for the LUT. */
```

Fragment shader: sample the thickness texture, multiply by `uFilmIndex` to get optical
thickness, fetch the LUT, multiply by `uExposure`, encode sRGB. Rupture as
`uRupture = vec4(x, y, r, rimWidth)` — inside `r`, output `uBackground`; within the rim,
a bright collecting edge; outside, the film. **No `highp` interference math is needed any
more** — the LUT removed it. Handle `webglcontextlost` with `preventDefault()`.
