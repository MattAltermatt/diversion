describe('noise', () => {

  // its bounds, so a span test over it measures concentration, not the bug.
  it('spans 0..1 at ONE octave — an arithmetic-shift hash caps this at ~0.5', () => {
    const n = unitNoise(1)
    let lo = 1, hi = 0
    for (let i = 0; i < 20000; i++) {
      const v = n((i % 200) * 0.37, Math.floor(i / 200) * 0.41)
      lo = Math.min(lo, v); hi = Math.max(hi, v)
    }
    expect(lo).toBeLessThan(0.05)
    expect(hi).toBeGreaterThan(0.95)
  })

  it('is deterministic for a seed', () => {
    expect(makeFbm(7)(1.5, 2.5)).toBe(makeFbm(7)(1.5, 2.5))
  })

  // ⚠️ THE DIRECTION IS x-FINER, and two drafts got it backwards. The probe's
  // comment says "x ~3.4x coarser… bands run across the frame"; its code spans
  // 17 units across the width against 15 down the height, so x is sampled FINER
  // and the bands elongate DOWNWARD. Assert fx/fy, never fy/fx.
  //
  // ⚠️ AND IT MUST AGGREGATE. A single scanline cannot see a 15% effect: per-line
  // the faithful field ranges 0.891–1.514 and an isotropic one 0.777–1.277 —
  // fully overlapping, so a one-line test is a coin flip. A draft of this plan
  // measured on one line, concluded the effect was unseparable, and deleted the
  // test. Aggregated over 6 seeds x 6 offsets it separates cleanly:
  //     faithful (17/15)    fx/fy = 1.146
  //     no anisotropy       fx/fy = 0.996
  //     the comment's 3.4   fx/fy = 3.377
  it('is anisotropic in the direction the probe CODE specifies — x finer', () => {
    const SEEDS = [3, 11, 77, 404, 9001, 123]
    const OFFS = [0.7, 3.3, 7.1, 13.9, 21.5, 37.2]
    let fx = 0, fy = 0
    for (const seed of SEEDS) {
      const b = warpedBands(seed)
      for (const off of OFFS) {
        for (const along of ['x', 'y'] as const) {
          let n = 0, prev = Math.sign(along === 'x' ? b(0, off) : b(off, 0))
          for (let i = 1; i < 3000; i++) {
            const s = Math.sign(along === 'x' ? b(i * 0.01, off) : b(off, i * 0.01))
            if (s !== prev) { n++; prev = s }
          }
          if (along === 'x') fx += n; else fy += n
        }
      }
    }
    expect(fx / fy).toBeGreaterThan(1.10)   // isotropic measures 0.996
    expect(fx / fy).toBeLessThan(1.60)      // the comment's 3.4 measures 3.377
    expect(fy).toBeGreaterThan(200)         // non-vacuity

## Accepted risks

**1. No sweep; the drawing hard-cuts to a reseed.**
- *Objection:* the spec's prose called the piece one that is "swept away".
- *Cheaper alternative:* a directional erase over the ink layer.
- *Why rejected:* the spec already deleted "swept away" as a distinctness claim (`squiral` ships a
  wipe), it is the one subsystem with zero evidence in the probe, and it must stay
  chunk-independent — a property already got wrong twice. Filed as a follow-up. **The hold/reseed
  cycle itself is NOT deferred** — it is Task 10, because without it the piece redraws one picture
  forever.

**2. `cellFills` and `pastel` are cut from v1.**
- *Objection:* the sikku photographs show colour filled into cells, and the probe implements it.
- *Cheaper alternative:* port the probe's 76-line `fillCells`.
- *Why rejected:* it needs a fourth layer, a half-res `getImageData` flood fill, and a hardcoded
  7-colour palette outside the #256 canon — and it ships **off by default**. The first draft listed
  both fields in the schema with no implementing task anywhere, which is worse than either shipping
  or cutting. Follow-up issue.

**3. The coloured chalk does not clear 3:1; the structure does.**
- *Objection:* invariant #5 says err toward more contrast, and the chalks measure 1.08–2.64 on a
  warm ground.
- *Cheaper alternative:* default to `dusk`, where every chalk clears 3:1.
- *Why rejected:* ⚠️ **the earlier version of this entry was a strawman** — it framed the choice as
  "warm floor vs dusk" and defaulted to **ochre**, the one warm ground whose *structure* also fails
  (2.88). Owner picked **concrete** (2026-09-17) from a rendered A/B
  (`docs/mockups/2026-09-17-kolam-ground-ab.jpeg`): the white armature clears the bar at **3.07**,
  and — the reason visible in the capture — ochre shares a hue with its own turmeric and cream
  chalks, so they vanish into the floor, while on concrete every chalk in the palette separates.
  What remains is narrow and deliberate: chalk is decorative, sits on small bounded forms, and is
  read by hue, not luminance. The structure carries the composition and it passes. `dusk` ships as a
  preset.
