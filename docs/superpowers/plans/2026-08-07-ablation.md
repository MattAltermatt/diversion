> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `src/diversions/ablation/` — a 2D diversion where lasers riding a rectangular track peel a quantized contour-map picture from the outside in, then a new picture resolves in and it repeats.

**Architecture:** Six pure modules (`field`, `front`, `scheduler`, `lasers`, plus `schema`/`presets`) with no canvas dependency, orchestrated by `ablation.ts` and drawn by `render.ts`. The picture is a `Uint8Array` of palette indices plus an `alive` mask; the erosion front is four lazily-advanced integer arrays; the picture is drawn from a persistent offscreen canvas patched only where cells die.

**Tech Stack:** TypeScript, Zod 4, Vitest, Canvas 2D. Framework helpers: `mulberry32` + `makeNoise3D` (`src/framework/rng.ts`), `hexToRgb` (`src/framework/color.ts`), `defineDiversion` (`src/framework/types.ts`).

**Spec:** `docs/superpowers/specs/2026-08-07-ablation-design.md` — read it before starting. Section references below (§N) point at it.

**Interfaces:**

- Produces:
  ```ts
  export interface Field {
    cols: number
    rows: number
    bands: number          // === palette length
    idx: Uint8Array        // cols*rows, palette index per cell
    alive: Uint8Array      // cols*rows, 1 = alive, 0 = destroyed
    aliveCount: number
  }
  export interface FieldOptions {
    seed: number
    cols: number
    rows: number
    bands: number
    featureSize: number    // cells per noise feature
    roughness: number      // 0..1 octave weighting
  }
  export function buildField(opts: FieldOptions): Field
  export function cellAt(f: Field, col: number, row: number): number  // → cell index
  ```

**Why quantile, not equal-width (§2):** slicing the noise value range into equal slices leaves the extreme bands nearly empty on most seeds, so the palette's first and last colours barely appear. Cut at equal *counts* instead. Do it with a 4096-bin value histogram and a cumulative scan — O(n), no sort of a 240,000-element array.

```ts
import { makeNoise3D } from '../../framework/rng'

export interface Field {
  cols: number
  rows: number
  bands: number
  idx: Uint8Array
  alive: Uint8Array
  aliveCount: number
}

export interface FieldOptions {
  seed: number
  cols: number
  rows: number
  bands: number
  featureSize: number
  roughness: number
}

export function cellAt(f: Field, col: number, row: number): number {
  return row * f.cols + col
}

const BINS = 4096

/** Fractal noise sampled at cell resolution, then quantized by QUANTILE so every
 *  band gets roughly equal mass (spec §2). Equal-width slicing would leave the
 *  extreme bands nearly empty and make "palette length is the band count" a lie. */
export function buildField(opts: FieldOptions): Field {
  const { seed, cols, rows, bands, featureSize, roughness } = opts
  const n = cols * rows
  const noise = makeNoise3D(seed)
  const raw = new Float32Array(n)

  // Octaves: base frequency from featureSize (cells per feature), each octave
  // doubling frequency and scaled by `roughness`.
  const base = 1 / Math.max(1, featureSize)
  const octaves = 3
  let min = Infinity
  let max = -Infinity
  for (let row = 0; row < rows; row++) {
    for (let col = 0; col < cols; col++) {
      let v = 0
      let amp = 1
      let freq = base
      for (let o = 0; o < octaves; o++) {
        v += amp * noise(col * freq, row * freq, o * 17.3)
        freq *= 2
        amp *= roughness
      }
      raw[row * cols + col] = v
      if (v < min) min = v
      if (v > max) max = v
    }
  }

  // Quantile cut points via a value histogram (O(n), no sort).
  const span = max - min || 1
  const hist = new Uint32Array(BINS)
  const bin = new Uint16Array(n)
  for (let i = 0; i < n; i++) {
    const b = Math.min(BINS - 1, Math.floor(((raw[i] - min) / span) * BINS))
    bin[i] = b
    hist[b]++
  }
  // cut[k] = first bin belonging to band k+1
  const cut = new Uint16Array(Math.max(0, bands - 1))
  let cum = 0
  let k = 0
  for (let b = 0; b < BINS && k < bands - 1; b++) {
    cum += hist[b]
    while (k < bands - 1 && cum > ((k + 1) * n) / bands) {
      cut[k] = b + 1
      k++
    }
  }
  for (; k < bands - 1; k++) cut[k] = BINS

  const idx = new Uint8Array(n)
  for (let i = 0; i < n; i++) {
    const b = bin[i]
    let band = 0
    while (band < bands - 1 && b >= cut[band]) band++
    idx[i] = band
  }

  const alive = new Uint8Array(n).fill(1)
  return { cols, rows, bands, idx, alive, aliveCount: n }
}
```

  ```ts
  export const EDGE = { top: 0, right: 1, bottom: 2, left: 3 } as const
  export type Edge = (typeof EDGE)[keyof typeof EDGE]

  export interface Front {
    top: Int32Array     // per column: topmost alive row,    rows  = none left
    bottom: Int32Array  // per column: bottommost alive row, -1    = none left
    left: Int32Array    // per row:    leftmost alive col,   cols  = none left
    right: Int32Array   // per row:    rightmost alive col,  -1    = none left
  }
  export function buildFront(f: Field): Front
  /** Lane = column for top/bottom, row for left/right. Returns the cell index of
   *  the outermost survivor in that lane, or -1 if the lane is empty. Advances the
   *  cached front past cells killed from another edge — amortised O(1). */
  export function frontCell(f: Field, fr: Front, edge: Edge, lane: number): number
  /** Marks a cell dead and decrements aliveCount. Fronts are lazy caches, so this
   *  does NOT need to update them. */
  export function killCell(f: Field, cell: number): void
  /** Counts the palette index of every lane's outermost survivor, across all four
   *  edges. This — not the whole picture — is what the scheduler samples (§5). */
  export function exposedHistogram(f: Field, fr: Front, out: Uint32Array): Uint32Array
  ```

**Why fronts are lazy caches:** a cell can be killed by a laser on *any* edge, so an edge's cached front goes stale without that edge knowing. `frontCell` walks forward past dead cells and rewrites the cache; each cell is skipped at most once per direction, so the amortised cost stays O(1). `killCell` therefore stays trivial.

```ts
import type { Field } from './field'

export const EDGE = { top: 0, right: 1, bottom: 2, left: 3 } as const
export type Edge = (typeof EDGE)[keyof typeof EDGE]

export interface Front {
  top: Int32Array
  bottom: Int32Array
  left: Int32Array
  right: Int32Array
}

export function buildFront(f: Field): Front {
  return {
    top: new Int32Array(f.cols),                       // starts at row 0
    bottom: new Int32Array(f.cols).fill(f.rows - 1),
    left: new Int32Array(f.rows),                      // starts at col 0
    right: new Int32Array(f.rows).fill(f.cols - 1),
  }
}

export function killCell(f: Field, cell: number): void {
  if (cell < 0 || f.alive[cell] === 0) return
  f.alive[cell] = 0
  f.aliveCount--
}

export function frontCell(f: Field, fr: Front, edge: Edge, lane: number): number {
  const { cols, rows, alive } = f
  if (edge === EDGE.top) {
    let row = fr.top[lane]
    while (row < rows && alive[row * cols + lane] === 0) row++
    fr.top[lane] = row
    return row < rows ? row * cols + lane : -1
  }
  if (edge === EDGE.bottom) {
    let row = fr.bottom[lane]
    while (row >= 0 && alive[row * cols + lane] === 0) row--
    fr.bottom[lane] = row
    return row >= 0 ? row * cols + lane : -1
  }
  if (edge === EDGE.left) {
    let col = fr.left[lane]
    while (col < cols && alive[lane * cols + col] === 0) col++
    fr.left[lane] = col
    return col < cols ? lane * cols + col : -1
  }
  let col = fr.right[lane]
  while (col >= 0 && alive[lane * cols + col] === 0) col--
  fr.right[lane] = col
  return col >= 0 ? lane * cols + col : -1
}

export function exposedHistogram(f: Field, fr: Front, out: Uint32Array): Uint32Array {
  out.fill(0)
  for (let col = 0; col < f.cols; col++) {
    const t = frontCell(f, fr, EDGE.top, col)
    if (t >= 0) out[f.idx[t]]++
    const b = frontCell(f, fr, EDGE.bottom, col)
    if (b >= 0) out[f.idx[b]]++
  }
  for (let row = 0; row < f.rows; row++) {
    const l = frontCell(f, fr, EDGE.left, row)
    if (l >= 0) out[f.idx[l]]++
    const r = frontCell(f, fr, EDGE.right, row)
    if (r >= 0) out[f.idx[r]]++
  }
  return out
}
```

  ```ts
   *  targeting bias: 0 = flat over exposed bands, 1 = strictly proportional,
  ```

**The trap:** `Math.pow(0, 0)` is `1` in JavaScript. At `k = 0` an un-guarded implementation gives every *extinct* band equal weight with every exposed one, so lasers get minted hunting colours that no longer exist. Guard on `hist[i] === 0 → weight 0` explicitly.

```ts
/** New lasers draw their colour from what is EXPOSED right now (spec §5), never
 *  from the whole picture — that is what makes deadlock structurally impossible.
 *  A strictly proportional draw starves minority colours (5% of twelve lasers is
 *  0.6, i.e. usually absent), so weights are tempered by an exponent first. */
export function temperedWeights(hist: Uint32Array, k: number): Float64Array {
  const w = new Float64Array(hist.length)
  let sum = 0
  for (let i = 0; i < hist.length; i++) {
    // NB Math.pow(0, 0) === 1 — an extinct band must be excluded explicitly, or
    // k=0 mints lasers hunting colours that no longer exist.
    const v = hist[i] === 0 ? 0 : Math.pow(hist[i], k)
    w[i] = v
    sum += v
  }
  if (sum > 0) for (let i = 0; i < w.length; i++) w[i] /= sum
  return w
}

export function temperedPick(hist: Uint32Array, k: number, rand: () => number): number {
  const w = temperedWeights(hist, k)
  let sum = 0
  for (let i = 0; i < w.length; i++) sum += w[i]
  if (sum <= 0) return -1
  let r = rand() * sum
  for (let i = 0; i < w.length; i++) {
    r -= w[i]
    if (r < 0) return i
  }
  for (let i = w.length - 1; i >= 0; i--) if (w[i] > 0) return i // float slop
  return -1
}
```

```ts
import { EDGE, type Edge } from './front'

export interface Geom {
  px: number; py: number
  pw: number; ph: number
  cell: number
  cols: number; rows: number
  gap: number
  perimeter: number
  seg: [number, number, number, number]
}

export interface TrackPoint {
  x: number; y: number
  edge: Edge
  dx: number; dy: number
  lane: number
  laneCentre: number
}

export interface Laser {
  s: number
  band: number
  charge: number
  maxCharge: number
  laps: number
  lane: number
  armed: boolean
}

export function makeLaser(s: number, band: number, charge: number): Laser {
  return { s, band, charge, maxCharge: charge, laps: 0, lane: -1, armed: false }
}

/** Picture fills the canvas minus the track margin, snapped down to whole cells. */
export function makeGeom(size: { width: number; height: number }, cell: number, gap: number): Geom {
  const margin = gap + Math.max(4, gap * 0.5)
  const availW = Math.max(cell, size.width - margin * 2)
  const availH = Math.max(cell, size.height - margin * 2)
  const cols = Math.max(1, Math.floor(availW / cell))
  const rows = Math.max(1, Math.floor(availH / cell))
  const pw = cols * cell
  const ph = rows * cell
  const px = Math.round((size.width - pw) / 2)
  const py = Math.round((size.height - ph) / 2)
  const w = pw + gap * 2
  const h = ph + gap * 2
  const seg: [number, number, number, number] = [w, h, w, h]
  return { px, py, pw, ph, cell, cols, rows, gap, perimeter: 2 * (w + h), seg }
}

export function trackPoint(g: Geom, sRaw: number): TrackPoint {
  let s = sRaw % g.perimeter
  if (s < 0) s += g.perimeter
  const tx = g.px - g.gap
  const ty = g.py - g.gap
  const [s0, s1, s2] = [g.seg[0], g.seg[0] + g.seg[1], g.seg[0] + g.seg[1] + g.seg[2]]

  if (s < s0) {
    const x = tx + s
    const lane = laneOf(x - g.px, g.cell, g.cols)
    return { x, y: ty, edge: EDGE.top, dx: 0, dy: 1, lane, laneCentre: lane < 0 ? NaN : g.px - tx + (lane + 0.5) * g.cell }
  }
  if (s < s1) {
    const d = s - s0
    const y = ty + d
    const lane = laneOf(y - g.py, g.cell, g.rows)
    return { x: tx + g.seg[0], y, edge: EDGE.right, dx: -1, dy: 0, lane, laneCentre: lane < 0 ? NaN : s0 + (g.py - ty) + (lane + 0.5) * g.cell }
  }
  if (s < s2) {
    const d = s - s1
    const x = tx + g.seg[0] - d
    const lane = laneOf(x - g.px, g.cell, g.cols)
    return { x, y: ty + g.seg[1], edge: EDGE.bottom, dx: 0, dy: -1, lane, laneCentre: lane < 0 ? NaN : s1 + (g.seg[0] - (g.px - tx) - (lane + 0.5) * g.cell) }
  }
  const d = s - s2
  const y = ty + g.seg[1] - d
  const lane = laneOf(y - g.py, g.cell, g.rows)
  return { x: tx, y, edge: EDGE.left, dx: 1, dy: 0, lane, laneCentre: lane < 0 ? NaN : s2 + (g.seg[1] - (g.py - ty) - (lane + 0.5) * g.cell) }
}

function laneOf(offset: number, cell: number, count: number): number {
  if (offset < 0) return -1
  const lane = Math.floor(offset / cell)
  return lane >= count ? -1 : lane
}

/** Spec §4 rule 4: one shot per lane, taken at the lane's centre. Entering a new
 *  lane re-arms; crossing that lane's centre while armed spends the arm. */
export function advance(g: Geom, l: Laser, ds: number): boolean {
  const before = trackPoint(g, l.s)
  const next = l.s + ds
  if (next >= g.perimeter) l.laps++
  l.s = next % g.perimeter
  const after = trackPoint(g, l.s)

  if (after.lane !== l.lane) {
    l.lane = after.lane
    l.armed = after.lane >= 0
  }
  if (!l.armed || after.lane < 0) return false
  // Crossed the lane centre? Compare against the segment-local perimeter coords.
  const crossed = before.lane !== after.lane
    ? l.s >= after.laneCentre || after.laneCentre <= 0
    : before.s0Passed(after.laneCentre, l.s)
  if (crossed) {
    l.armed = false
    return true
  }
  return false
}
```

**Note on `advance`:** the `crossed` expression above is a sketch and will not compile — `TrackPoint` has no `s0Passed`. Replace it with a straightforward comparison in perimeter space: record `prevS` before the move, and fire when `prevS < after.laneCentre <= l.s` (handling the wrap by testing against `l.s + g.perimeter` when `l.s < prevS`). Keep the rule exactly: **armed, in a valid lane, and the lane's centre was crossed by this step.**

  ```ts
  export function resizeState(s: AblationState, size: Size): void
  ```

**Step order per frame** — this ordering matters:

1. Age `dying` and `bolts`; drop expired.
2. Advance every laser by `speed * dt`. For each that reports a shot: read `frontCell` for its edge+lane; if that cell's band matches the laser's band, `killCell`, push a `Dying`, push a `Bolt`, decrement charge.
3. Eject lasers with `charge <= 0` **or** `laps >= lapCap`.
4. Recompute `hist` via `exposedHistogram`.
5. Mint arrivals: `arrivalDebt += arrivalRate * dt`; while `arrivalDebt >= 1`, draw a band via `temperedPick(hist, targetingBias, rand)` — **skip entirely if it returns -1** (nothing exposed, so nothing to hunt, which is what makes the run-to-empty quiet beat happen on its own) — and either place a laser at the gate if `lasers.length < capacity` or push the band onto `queue` (capped at `capacity`).
6. Drain the queue into free slots.
7. If `field.aliveCount === 0` **and** `lasers.length === 0` **and** `dying.length === 0`, regenerate: new field from `seed + pictures + 1`, new front, `pictures++`, clear the buffer so `render.ts` rebuilds it.

**Ejection is instant** for now (the laser is removed from the array). Do not build a fly-off animation — that is polish for Task 8 if it reads badly.

- Produces: `export function render(s: AblationState, ctx: CanvasRenderingContext2D): void`, and `index.ts`'s default export `Diversion`.

**Draw order:**

1. `fillRect` the whole canvas in `background`.
2. Ensure the offscreen picture buffer exists (`document.createElement('canvas')` sized to `pw × ph`, following `src/diversions/dla/render.ts`). If `s.buffer` is null, rebuild it by filling every alive cell; otherwise reuse it. **On each kill in `step`, `render` patches that one cell to `background` in the buffer** — do this by draining a small `pendingPatch` list the step function appends to, not by rescanning the grid.
3. `drawImage(buffer, px, py)`.
4. Dying cells: for each, `fillRect` a square shrinking from full cell size to 0 over its lifetime, in its band colour faded toward the background. Set `ctx.globalAlpha` explicitly every iteration.
5. The track: a thin stroked rectangle at the track rect, dim.
6. Lasers: a small capsule at each `trackPoint`, in its band colour, at `charge / maxCharge` intensity. Set `globalAlpha = 1` before any fill whose colour string already carries alpha.
7. Bolts: a bright line from the laser's track point to the struck cell's centre, in the band colour, fading over `BOLT_MS`.
8. Queue: dots outside the gate, one per queued band, in that band's colour.

**Register in `index.ts`** with `defineDiversion`: `id: 'ablation'`, `kind: '2d'`, `title: 'Ablation'`, a one-line `description`, `schema: ablationSchema`, `presets: ablationPresets`, and `setup` / `frame` / `resize` / `update` delegating to `createState` / `step`+`render` / `resizeState` / `applyConfig`.
