# Neural CA Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a `webgl` diversion (#148) that runs a pretrained Self-Organising-Textures neural cellular automaton fully on-GPU, growing an endless, calmly-churning abstract texture from a seed.

**Architecture:** All-GPU WebGL2, inference-only. ~16-channel cell state across 4× RGBA32F render targets (MRT), ping-ponged each step. The update shader reimplements hexells' `ca.js` math (hex perception → dense→ReLU→dense → stochastic mask); weights are loaded from a vendored `models.json` (`znah/hexells`, Apache-2.0). The display shader reads the visible RGB onto a hex lattice. Follows the `plasma` (webgl contract) and `physarum`/`grayscott` (multi-pass FBO) references.

**Tech Stack:** Vite + React 19 + TypeScript 6 + Zod 4 + Vitest 4; WebGL2 (MRT, RGBA32F, NEAREST); the framework's `defineDiversion` contract + Zod-schema-driven config/URL codec.

**Spec:** `docs/superpowers/specs/2026-06-29-neural-ca-diversion-design.md`

> ⚠️ **Architecture corrected by the Task 1 spike — see `src/diversions/neural-ca/ARCHITECTURE.md` (authoritative).**
> The GPU internals below (Tasks 3–4) were written from generic-NCA literature and are **superseded**:
> hexells uses **12 channels** in **single uint8 channel-tiled textures (NOT MRT, NOT RGBA32F)**, weights are
> **base64-PNG images** loaded browser-native, and the rule is hex-conv perception + per-cell alignment + 2 dense
> layers with per-model packed weights. Tasks 3–4 = faithfully port hexells' 4 shader programs + tile-addressing
> into our framework. Effort revised **M → L–XL** (porting against a working reference, not research).

0. **De-risk** — source + vendor the weights, document the exact architecture, write the parser. Resolves the two make-or-break unknowns (models.json format, hex architecture).
1. **Vertical slice** — one texture rendering correctly on-GPU, Chrome-verified against the real hexells output (the fidelity gate).

## Task 4 (Phase 1): Update + display shaders — ONE texture renders (🚦 FIDELITY GATE)

**Why:** The heart of the port and the make-or-break risk. The GLSL is authored **against `ca.js`** using the dims documented in Task 1 (this is the genuine-research probe — exact constants come from the spike, not guessed here). **Lead-inline** — Chrome verification IS the acceptance test.

**Files:**
- Modify: `src/diversions/neural-ca/gl.ts` (add programs + step/render)
- Modify: `src/diversions/neural-ca/index.ts` (frame loop, context-loss)

- [ ] **Step 1: Weight upload.** In `initGL`, pack `dense1`/`dense2` weights+biases into a `RGBA32F` "weight texture" (or uniform arrays if small enough) and sample them in the shader. Document the packing layout in a comment.

- [ ] **Step 2: SIM program** — `SIM_FRAG` does, per fragment (cell), reading from the `C/4` MRT inputs:
  1. **Perception:** for each channel, apply the documented hex filters at the documented hex neighbor offsets → build the length-`P` perception vector.
  2. **dense1:** `P→H` matmul (loop over weight texture) + bias + **ReLU**.
  3. **dense2:** `H→C` matmul + bias (linear) → state delta.
  4. **Stochastic mask:** per-cell hash(seed, coord, step) < `fireRate` gates whether the delta is applied; write new state to the `C/4` MRT outputs.

  Write the GLSL to match `ca.js` exactly (offsets, filter weights, layer order, mask). **Outputs use `layout(location=k)` for MRT.**

- [ ] **Step 3: DISPLAY program** — `DISPLAY_FRAG` reads the visible RGB (channels 0–2) of the state and renders onto the **hex lattice** (axial→pixel mapping) to screen. Opaque.

- [ ] **Step 4: `step()` + `render()`** in `gl.ts`: `step` runs one SIM pass (bind write FBO, draw, swap ping-pong); `render` runs DISPLAY to the default framebuffer.

- [ ] **Step 5: `frame()`** in `index.ts`: set viewport; run `floor(speed)` (+ fractional accumulator) `step()`s; `render()`. Add `webglcontextlost` handler that `preventDefault()`s and a `restored` handler that rebuilds via `setup`. `teardown` calls `disposeGL`.

- [ ] **Step 6: 🚦 FIDELITY GATE (Chrome).** Open `http://localhost:5180/d/neural-ca/play?mute=1`. The hardcoded first model MUST grow into a texture **recognizably matching its hexells counterpart** at `https://znah.net/hexells/` (same family of pattern, churning, stable-not-exploding). Screenshot; describe luminance/structure. **If it diverges** (noise, uniform color, explosion): debug perception offsets / weight packing / layer order against `ca.js` before proceeding — do NOT build controls on a broken core. If irrecoverable, escalate (fallback = train-our-own, re-scopes to multi-session).

- [ ] **Step 7: Commit.** `git commit -m "feat(neural-ca): on-GPU update+display shaders — single texture renders (#148)"`
