| 2026-09-14 | [Parquet Deformation — grid keys](2026-09-14-parquet-grid.jpeg) / [fractal](2026-09-14-parquet-fractal.jpeg) / [organic](2026-09-14-parquet-organic.jpeg) ([source](2026-09-14-parquet-deformation.html), interactive) | #383 the brainstorm mockup: a plain square lattice whose **edge curve** is a function of position, after Kaplan, *Curve Evolution Schemes for Parquet Deformations* (Bridges 2010). | 2026-09-14 | Parquet Deformation — Amplitude: [organic 1.7×](2026-09-14-parquet-organic-amp17.jpeg) / [organic 2.5×](2026-09-14-parquet-organic-amp25.jpeg) / [grid keys 1.8×](2026-09-14-parquet-grid-amp18.jpeg) | #383 the Amplitude knob (owner ask, 2026-09-14: make the deformation cover more of the tile instead of hugging the lattice line). It scales the edge curve's perpendicular offset; both tiles sharing an edge scale it identically, so the tiling stays gap-free. **1.7× is where organic wants to live** — the curls reach into the tile and knot at the lattice vertices. **2.5× is past the limit**: a tile's own four edges overlap each other, the two-colour checkerboard read collapses. ⚠️ **For the rectilinear grid scheme a plain scale is the wrong mechanism** — it stretches the perpendicular grid step while leaving the parallel one alone, so the keys stop being square and pick up off-axis edges. That scheme needs its excursion widened in *grid units* (a taller fine grid), not stretched |
| 2026-09-14 | Parquet Deformation — saturation knee: [knee, span 7](2026-09-14-parquet-organic-knee.jpeg) / [**knee, span 14 — the shipped look**](2026-09-14-parquet-organic-knee-wide.jpeg) | #383 the organic scheme stops changing shape at about a quarter of its run — measured in the mockup's own generator: arc length 1.00 → 2.81 → **3.93 at stage 12** → 3.53 at stage 48, and mean per-stage point movement is **7.9× lower** after stage 24 than before stage 12.
