Config screen on a phone — A/B

Both frames are 390×844, the measured iPhone-class viewport. Shipped today at this width, the Config screen is a 320px sidebar beside a 70px preview sliver with the Play button clipped off the right edge. Content and tokens below are taken from the real Falling Sand schema and src/framework/theme.css, so this reads as the product, not a wireframe.

A · Stacked, sticky preview

Preview pins to the top at ~380px; the whole control panel flows beneath it and the page scrolls normally. No hidden state — everything is one scroll away, always.
