Bundle-stroke probe

#349 · does drawing every path as a BUNDLE of parallel strokes carry the kolam look? Drag Strokes per bundle from 1 to 8 and watch the same composition change character.

The answer under test

1 stroke = a plotted outline. 5–8 = a hand that went round the same path repeatedly, which is what the reference photographs actually show.

The composition

0 = bare registers on open ground. Rising, it switches on nesting (a motif inside each motif) then fills the bare annuli between registers. 1.0 is festival-dense; the gallery's ethos is calm, so the interesting range is probably 0.3–0.6.

How often a register is drawn in coloured chalk instead of rice flour. Each drawing picks 2–3 chalks and reuses them, the same rule the motifs follow — a free pick per register reads as a colour test card. A register is always ONE colour, or the N-fold symmetry breaks.

Colour goes in the FILLS, never the lines — a filled region is a large area, and the white boundary carries the legibility so the colour never has to. Pastel lifts each powder toward white so it clears a warm ground upward instead of fighting through it.
