# Contact-sheet montages

The labelled montages built during the 2026-09-17 sourcing pass, one per candidate
issue. They are kept because **they are wider than the curated set**: each montage
shows every candidate that was pulled for that issue, including the ones that did
not make it into the sibling folders — so the montage is the record of what was
looked at and rejected, not just what was kept.

Two things in `montage-349-kolam.jpg` are worth knowing about and exist nowhere else
in this repo: a **hexagonal/triangular dot lattice** (kolam is not only drawn on a
square grid), and an elaborate kolam carrying a **red-ochre border** drawn around the
white line.

Downscaled to 1400 px on the long edge. `../tools/` holds the Python that fetched the
images and built these sheets, so the pass is reproducible.
