# 🗃️ Backlog → GitHub Issues

The backlog now lives in **[GitHub Issues](https://github.com/MattAltermatt/diversion/issues)** — that's the single source of truth for bugs, framework work, and new-diversion ideas going forward.

Handy filters:

- [`framework`](https://github.com/MattAltermatt/diversion/issues?q=is%3Aissue+is%3Aopen+label%3Aframework) — shared framework / contract work
- [`diversion-content`](https://github.com/MattAltermatt/diversion/issues?q=is%3Aissue+is%3Aopen+label%3Adiversion-content) — new pieces (next up: a WebGL raymarcher)
- [`screensaver`](https://github.com/MattAltermatt/diversion/issues?q=is%3Aissue+is%3Aopen+label%3Ascreensaver) — long-run / unattended fitness
- [`bug`](https://github.com/MattAltermatt/diversion/issues?q=is%3Aissue+is%3Aopen+label%3Abug)

Shipped work is recorded as closed issues + the [Releases](https://github.com/MattAltermatt/diversion/releases) page.
